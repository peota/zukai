# Agents (replacing Ask) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove Ask entirely and let the user start a known AI coding agent CLI (Claude Code, Codex, Gemini, OpenCode, Cursor) as a Terminal in the folder of the note they're on.

**Architecture:** An agent is a Terminal whose shell is started with the agent's command and then left at a prompt. Rust owns a fixed agent list, detects installed agents through the user's interactive login shell (Unix) or a PATH search (Windows), and accepts only an agent id from the UI. The UI adds one menu (Terminal + "Start an agent"), opened from a chevron beside the Terminal panel's +, from an Agent button in the status bar, and from Mod+J.

**Tech Stack:** Tauri 2, Rust (`portable-pty`), React + TypeScript, vitest, Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-24-agents-design.md`. Read it, and `docs/superpowers/specs/2026-11-20-terminal-design.md` for the Terminal it builds on.

## Global Constraints

- The UI never sends a command string. `terminal_open` takes an optional agent **id**, and an unknown id is an error.
- The agent list, in this order: `claude-code` "Claude Code" `claude`; `codex` "Codex" `codex`; `gemini` "Gemini" `gemini`; `opencode` "OpenCode" `opencode`; `cursor` "Cursor" `cursor-agent`.
- On Windows, only `.exe`, `.cmd` and `.bat` count as installed, and the launch uses the found file name with its extension (for example `claude.cmd`). Never pass `-ExecutionPolicy`.
- The folder still passes the existing grant check (`folder(g, cwd)`). Agents use the Terminal default-folder rule, and the panel's + uses `plusFolder`.
- Agent detection never runs at startup, only when the menu opens. It runs off the UI thread and on every opening.
- Nothing of Ask remains: no `ai` module, no `keyring` or `ureq` crates, no `askWidth`, no `toggleAsk`, no AI Settings section, no `ask` icon and no CONTEXT.md Ask section. No keychain or `ai.json` migration code (owner's decision).
- Status-bar notice when no folder qualifies: `Choose a Library folder to open a terminal` (the existing `NO_TERMINAL_FOLDER`).
- UI vocabulary: **Terminal**, **Agent**, **Start an agent**, **not installed**.
- Verify with `pnpm typecheck`, `pnpm test`, `pnpm lint`, and `cargo test` / `cargo clippy` in `src-tauri`.

## Review Focus

1. **An rc file that blocks or prints noise** (a prompt asking for input, a banner, oh-my-zsh updates). Detection must time out after 5 s, ignore everything except marker lines, and fall back to a PATH search. Pinned in Task 3 (`parse_detected` ignores noise; timeout falls back).
2. **Results arriving out of order or after the menu closed.** Opening the menu twice quickly must not let an older detection overwrite a newer one. Pinned in Task 5 (`useAgents` drops stale responses).
3. **Windows with only `claude.ps1`, or with both `.ps1` and `.cmd`.** The first is "not installed", and the second launches `claude.cmd`. Pinned in Task 2.
4. **Starting an agent with no qualifying folder** (a Scratchpad with no Library root). It shows the notice and opens nothing. Pinned in Task 7.
5. **The agent exits with an error or is interrupted with Ctrl+C.** The tab must still land at a live prompt. Pinned in Task 4 (the stand-in agent exits non-zero, and `echo ok` still runs).

### Task 3: Detecting installed agents, and `terminal_agents`

**Files:**
- Modify: `src-tauri/src/terminal/agents.rs`, `src-tauri/src/terminal/commands.rs`, `src-tauri/src/lib.rs` (register `terminal_agents`)

**Interfaces:**
- Consumes: `AGENTS`, `find_windows`, `shell_kind`, `ShellKind` (Task 2); `current_shell()` (`shell.rs`)
- Produces:
  - `pub const MARKER: &str = "__ZUKAI_AGENT__";`
  - `pub fn detect_script(kind: ShellKind, commands: &[&str]) -> String`:
    - Posix: `for c in claude codex …; do command -v "$c" >/dev/null 2>&1 && printf '%s%s\n' __ZUKAI_AGENT__ "$c"; done`
    - Fish: `for c in claude codex …; if type -q $c; printf '%s%s\n' __ZUKAI_AGENT__ $c; end; end`
  - `pub fn parse_detected(output: &str) -> Vec<String>`. It returns the command after `MARKER` on each line that starts with it (after trimming `\r`), and ignores all other lines.
  - `pub fn installed_commands() -> Vec<String>`:
    - Windows: `find_windows` for each agent, using Zukai's `PATH`.
    - Unix: it runs `current_shell().program` with `["-l","-i","-c", detect_script(...)]`, `stdin` null, `stderr` null and `stdout` piped, with a **5 s** limit (kill the child on timeout). If the run fails or times out, it falls back to a plain search of Zukai's `PATH` for each command (a file that exists and is executable).
  - `#[derive(Serialize)] #[serde(rename_all = "camelCase")] pub struct AgentInfo { id: String, name: String, installed: bool }`
  - `#[tauri::command] pub async fn terminal_agents() -> Vec<AgentInfo>`. It runs `installed_commands` in `tauri::async_runtime::spawn_blocking`, in `AGENTS` order.

  - `detect_script(ShellKind::Posix, &["claude","cursor-agent"])` contains `for c in claude cursor-agent; do` and `MARKER`.
  - The Fish one contains `type -q $c`.
  - `#[cfg(unix)]`: running `/bin/sh -c <detect_script(Posix, ["sh", "zukai-no-such-agent"])>` through the same runner returns `["sh"]`. Factor the runner as `fn run_detect(program: &Path, args: &[String], timeout: Duration) -> Option<String>` so it's testable.
  - `#[cfg(unix)]`: `run_detect` on `/bin/sh -c "sleep 10"` with a 200 ms timeout returns `None` within 2 s.
