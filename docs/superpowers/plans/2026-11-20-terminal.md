# Terminal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A VS Code-style Terminal panel, at the bottom or to the side of the editor, that holds several real shell sessions, each opened in a granted Library folder.

**Architecture:** A new Rust `terminal` module runs each shell in a PTY (`portable-pty`). It checks the starting folder with the Library's own folder check, streams output to the webview over a `tauri::ipc::Channel`, and kills the whole process tree on close and on quit. On the UI side, `src/terminal/` has pure modules (the state reducer, key routing, the default folder, labels, theme colors), a `useTerminals` hook, and a lazy-loaded `TerminalPanel` that mounts xterm.js. App places the panel with CSS, using a flex row or column, so switching position never remounts a terminal.

**Tech Stack:** Tauri 2, Rust (edition 2024): `portable-pty`, `sysinfo` (Unix), `windows-sys` (Windows). React 19 + TypeScript: `@xterm/xterm`, `@xterm/addon-fit`, `@xterm/addon-web-links`. Tests use Vitest + Testing Library (jsdom) and `cargo test`.

**Spec:** `docs/superpowers/specs/2026-11-20-terminal-design.md`

## Global Constraints

- **Words:** a **Terminal** is one shell session opened in a folder; the **Terminal panel** holds them. UI copy, verbatim:
  - `Open in terminal` (the menu item)
  - `New terminal`, `Kill terminal`, `Move to side`, `Move to bottom`, `Hide panel` (header buttons; also their tooltips and aria-labels)
  - `Process exited with code N`
  - `Choose a Library folder to open a terminal` (the notice)
- **Shortcuts:**
  - **Ctrl+`** toggles the panel and **Ctrl+Shift+`** opens a new terminal.
  - Both match `e.code === "Backquote"` with `ctrlKey`, on **every** platform, macOS included. They must not require Cmd.
- **Panel sizes:**
  - Bottom height: from 120 px to 70% of the window.
  - Side width: from 240 px to 70% of the workspace.
  - Defaults: `terminalPosition: "bottom"`, `terminalHeight: 280`, `terminalWidth: 480`.
- **Folder rule:** a terminal opens only in a folder that passes `library::commands::folder` (a granted root, or a folder inside one). The UI never passes a command, and Rust only ever starts the shell.
- **Default folder:**
  1. the active Tab's File's folder, if that File is under an available root or added folder
  2. else the Library root, if available
  3. else the first available added folder
  4. else none: show the notice
  The home folder is never used.
- **Shell:**
  - **Windows:** `pwsh.exe` on PATH → `powershell.exe` → `%COMSPEC%`.
  - **Unix:** `$SHELL` → the passwd shell → `/bin/zsh` (macOS) or `/bin/bash` (Linux) → `/bin/sh`, always started with `-l`.
  - **Extra env:** `TERM=xterm-256color`, `COLORTERM=truecolor`, `TERM_PROGRAM=zukai`, `TERM_PROGRAM_VERSION=<crate version>`.
- **Lifetime:**
  - Terminals are never restored. The panel starts hidden and its shown state isn't saved.
  - Killing the last terminal hides the panel.
  - Quit kills every process tree without asking.
  - Killing a terminal doesn't ask.
- **Key routing** (while a terminal has focus), in order:
  1. Ctrl+` and Ctrl+Shift+`, Ctrl+Tab and Ctrl+Shift+Tab go to the app.
  2. **macOS:** Cmd+C copies, Cmd+V pastes, and any other Cmd key goes to the app.
  3. **Windows and Linux:**
     - Ctrl+Shift+C copies, and Ctrl+Shift+V or Ctrl+V pastes.
     - Ctrl+C copies when there's a selection, and otherwise goes to the shell.
     - Ctrl with `=`, `+`, `-`, `0` (or the numpad add, subtract and 0 keys), `,` or Q goes to the app.
  4. Everything else goes to the shell.
- **Startup:** nothing from `src/terminal/TerminalPanel.tsx` or `@xterm/*` may be imported statically from `App.tsx` or anything on its static import graph. Only the pure modules (`model.ts`, `keys.ts`, `defaultFolder.ts`, `labels.ts`) and `useTerminals.ts`, which import no xterm, may be static.
- **Scrollback** is 5,000 lines. The font is `var(--z-font-mono)`, at the editor's `fontSize`.

## Review Focus

1. **Fast output.** `yes`, or a big `npm install` log, must not freeze the UI or lose bytes. Output is batched, and a multi-byte UTF-8 character split across reads must never show as `�`. Task 3 adds `utf8_tail_is_carried_across_reads`, and Task 4 adds `burst_output_arrives_complete_and_in_order`.
2. **App shortcuts typed into a shell.** On Windows, Ctrl+P, Ctrl+R, Ctrl+W and Ctrl+N in a focused terminal must reach the shell and must not open Quick open, reload or close a Tab. Task 7 adds `appIgnoresShellKeysInsideTerminal`.
3. **Switching position while something runs.** The xterm instance and its scrollback must survive bottom ↔ side, and so must hiding and showing the panel. Task 9 adds `positionSwitchKeepsTerminalMounted`.
4. **A grandchild outliving its terminal.** `npm run dev` starts `node`, which may start more children. Killing the terminal, or quitting, must end all of them. Task 2 adds `kill_tree_ends_grandchild`.
5. **A shell that exits by itself.** After `exit`, the tab stays with a dim `Process exited with code 0`, any key or × closes it, and nothing more is written to the dead PTY. Task 8 adds `exitedTerminalClosesOnAnyKey`, and Task 4 adds `write_after_exit_is_ignored`.

### Task 3: A PTY session (Rust, no Tauri)

**Files:**
- Modify: `src-tauri/Cargo.toml` (add `portable-pty`, the current release)
- Create: `src-tauri/src/terminal/session.rs`

**Interfaces:**
- Consumes: `ShellSpec`, `extra_env` (Task 1), and `tree::guard` / `TreeGuard` (Task 2)
- Produces:
  - `#[derive(Serialize, Clone)] #[serde(tag = "kind", rename_all = "camelCase")] pub enum TerminalEvent { Data { data: String }, Exit { code: Option<i32> } }`
  - `pub type Sink = Arc<dyn Fn(TerminalEvent) + Send + Sync>`
  - `pub struct Session` with:
    - `pub fn spawn(shell: &ShellSpec, cwd: &Path, cols: u16, rows: u16, sink: Sink) -> Result<Session, FileError>`
    - `pub fn write(&self, data: &[u8]) -> std::io::Result<()>` (`Ok(())` without writing once the shell has exited)
    - `pub fn resize(&self, cols: u16, rows: u16) -> std::io::Result<()>`
    - `pub fn kill(&self)` (`TreeGuard::kill`, then the child's wait is reaped by the waiter thread)
  - `pub fn utf8_split(buf: &[u8]) -> usize`: the length of the longest prefix that doesn't end inside a multi-byte character.
- How output flows:
  - A reader thread reads the PTY into a shared `Vec<u8>`.
  - A flusher thread wakes every 8 ms, or as soon as 64 KB is waiting. It sends `Data` with `String::from_utf8_lossy(&buf[..utf8_split(&buf)])` and keeps the tail for next time.
  - A waiter thread waits on the child, flushes what's left, then sends `Exit { code }`, exactly once.
  - The exact numbers are the builder's call (spec §8).

- [ ] **Step 1: Write the failing tests:**
  - `utf8_tail_is_carried_across_reads`: `utf8_split("aé".as_bytes()[..2])` is `1`. A full buffer gives its full length. A lone invalid byte that isn't a lead byte isn't held back.
  - `echo_round_trip`: spawn `current_shell()` in a tempdir, using a sink that pushes to an `mpsc`. Write `echo zukai-hi\r` (Windows) or `echo zukai-hi\n` (Unix), then `exit\r` or `exit\n`. Collect for up to 10 s. The joined `Data` contains `zukai-hi`, and the last event is `Exit { code: Some(0) }`.
  - `starts_in_cwd`: write `pwd` (Unix) or `(Get-Location).Path` (Windows), then exit. The output contains the tempdir's canonical path.
- [ ] **Step 2: Run them and check they fail.** Run `cargo test terminal::session`. Expected: compile failure.
- [ ] **Step 3: Implement `Session`.** Use `native_pty_system().openpty(PtySize{rows, cols, ..})`, and `CommandBuilder::new(program)` with `args`, `cwd` and the extra env. Call `tree::guard(child.process_id())` right after spawning. Drop the slave after spawning.
- [ ] **Step 4: Run them again.** Run `cargo test terminal::session`. Expected: all pass.

  - What `TerminalView` does:
    - It creates one `Terminal` on mount, `{ scrollback: 5000, fontFamily: "var(--z-font-mono)" resolved from computed style, fontSize, theme }`, and disposes it only on unmount.

      - copy: `navigator.clipboard.writeText(term.getSelection())`, then `clearSelection`. Return false.

      - app: return false.
      - shell: return true.
      - When `exited !== undefined`, any keydown calls `onClose()`.
    - On contextmenu it calls `preventDefault()`. With a selection it copies; otherwise it pastes `navigator.clipboard.readText()` through `term.paste`.
    - When `exited` changes from undefined, it writes `\r\n\x1b[2mProcess exited with code ${code ?? "?"}\x1b[0m\r\n`.
    - The `WebLinksAddon` handler is `onOpenUrl`.
    - The root element carries `data-z-terminal=""`.
