# Re-indent code Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Shift+Alt+F re-indent JS, TS, HTML, XML, CSS and SQL Tabs, keeping JSON Beautify as it is.

**Architecture:** `EditorHost`'s existing format effect, which handles the `format` command's "beautify" request, gains a second branch. For a language in `REINDENT_LANGUAGES` it dispatches a change from `indentRange` (`@codemirror/language`), covering the selected lines or the whole document.

**Tech Stack:** CodeMirror 6, React 19, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-19-reindent-design.md`

## Global Constraints

- **Languages that re-indent:** exactly `javascript`, `typescript`, `html`, `xml`, `css` and `sql`.
- **Untouched:** Python, YAML, Markdown, shell and plain text (no change), and read-only Tabs.
- **JSON:** unchanged (Beautify). Minify stays JSON-only.
- **Shortcut list:** the label becomes exactly `Format JSON / re-indent code`.
- **The edit:** one undo step, with `userEvent: "input.indent"`. Only leading whitespace changes.

## Review Focus

1. **The language may not be loaded yet.** It loads lazily, so pressing the key before it arrives must not throw or mangle the text. *(Test `reindent_before_language_loads_is_harmless`.)*
2. **A selection that starts or ends mid-line** re-indents those whole lines and no others. *(Test `reindent_selected_lines_only`.)*
3. **Multiple cursors:** re-indent the lines of every range. *(Covered by using all `state.selection.ranges`.)*

### Task 1: Re-indent on Shift+Alt+F

**Files:**
- Modify: `src/editor/EditorHost.tsx` (the format effect at about lines 706-716, plus a new `reindent(view): boolean`)
- Modify: `src/app/shortcutList.ts` (the label)
- Test: `src/editor/EditorHost.test.tsx` ("EditorHost format requests"), plus the existing shortcut-list or Settings test if one asserts the old label

**Interfaces:**
- `const REINDENT_LANGUAGES: ReadonlySet<LanguageId>` in EditorHost.tsx.
- `function reindent(view: EditorView): boolean`:
  - It returns whether anything changed.
  - With an empty selection it covers the whole document. Otherwise it covers the line ranges of each selection range.
  - It builds the changes with `indentRange(view.state, from, to)` and dispatches them with `userEvent: "input.indent"`, mapping the selection through them.
- **The effect:**
  - JSON → `formatJson` (unchanged).
  - `kind === "beautify"`, the language in `REINDENT_LANGUAGES` and the Tab not read-only → `reindent`.
  - Anything else → do nothing.
  - `onFormatResult` is called only for JSON, as today.
