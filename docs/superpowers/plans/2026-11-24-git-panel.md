# Git Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Zukai's git UI out of the Library tree into a Git view that swaps with the Library in the sidebar, adding a changes list, read-only diff tabs, and branch switch/create.

**Architecture:** Rust gains five read/write commands in `src-tauri/src/git/` behind the existing gate and runner. The frontend extends `useGitSync` with changes/branches for one selected folder, adds a `GitView` (folder picker, branch row, commit box, changes list, branch menu) in `src/ui/git/`, a `"diff"` tab kind rendered by a `DiffPane` on `@codemirror/merge`, a Files | Git switch in `Sidebar`, and a branch chip in `StatusBar`. The old git row and setup card are removed.

**Tech Stack:** Tauri v2, Rust 2024, React 19, TypeScript, Tailwind v4, CodeMirror 6 (+ `@codemirror/merge`), Vitest, lucide-react, pnpm.

**Spec:** `docs/superpowers/specs/2026-11-24-git-panel-design.md` (builds on `docs/superpowers/specs/2026-11-24-library-git-sync-design.md`, "the sync spec").

## Global Constraints

- Work on branch `feat/git-sync` in worktree `C:\repos\zukai\.claude\worktrees\git-sync`. Package manager is **pnpm** (`pnpm test`, `pnpm typecheck`, `pnpm lint`). Rust checks run in `src-tauri`: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`.
- Every git process goes through the existing `Git::run` (env `GIT_TERMINAL_PROMPT=0`, `GCM_INTERACTIVE=never`, `LC_ALL=C`, `LANGUAGE=C`, null stdin, `CREATE_NO_WINDOW`, timeouts). Never `std::process::Command` directly.
- Every new command is refused while Git sync is off and only accepts a `folder` that is exactly the Library root or an added root (reuse the existing gate helpers in `src-tauri/src/git/commands.rs`).
- Read commands (`git_changes`, `git_branches`, `git_head_file`) never take the busy lock; write commands (`git_switch`, `git_create_branch`) do.
- All refusals Rust words for the user use `GitKind::Refused` with the sentence as `detail` (the frontend shows `detail` verbatim for `refused`).
- Exact copy (verbatim):
  - Switch refused, dirty: `You have uncommitted changes. Commit first, then switch.`
  - Switch refused, unsaved (frontend): `Save or close N unsaved files first.` (singular: `Save or close 1 unsaved file first.`) with a `Save all` link.
  - Invalid branch name: `Not a valid branch name` · existing: `That branch already exists`
  - In progress tooltip: `Finish the rebase in a terminal first`
  - Not a repo: `This folder isn't synced yet.` · inside repo: `This folder is inside the git repo at <path>.` · no git: `Install git to sync folders.`
  - Diff states: `Binary file changed` · `Too large to show (over 1 MB)` · `No changes since the last commit.` · tab tooltip `Changes since last commit`
  - Changes: heading `CHANGES`, empty `No changes`, overflow `and N more files` after the first **500** rows.
  - Commit placeholder `Sync YYYY-MM-DD` (local date, existing `defaultCommitMessage()`), button `Commit & push` with `origin`, `Commit` without a remote.
  - Uncommitted dot title: `Uncommitted changes`.
- Diff size cap: **1 MB** (1,048,576 bytes) on either side. Binary: a NUL byte in the first 8,000 bytes.
- Shortcut: `Ctrl+Shift+G` (`Cmd+Shift+G` on mac) toggles the Git view.
- Visual system: DESIGN.md (now a map; full text in `.impeccable/design-full.md`). Colors only from `--z-*` tokens; Lucide icons at 16px; rows 30px with 6px radius; floats 10px radius with the float shadow; Label style for section headings; the amber `--z-warn` dot is 5px; no mono in chrome.
- **Any task that edits UI** (Tasks 4–9): before the first UI edit, run `.claude/skills/impeccable/scripts/impeccable.cmd context --target <the main file>` once and read `.claude/skills/impeccable/reference/craft-floor.md`.

## Review Focus

1. **File names with spaces, non-ASCII or quotes** (e.g. `notes/日本 plan "v2".md`): listed exactly, and their diff opens. Pinned by `changes_lists_odd_names_verbatim` (Task 1) and a `DiffPane` test using such a path (Task 4).
2. **Switching to a branch where an open tab's file doesn't exist**: the tab goes through the existing gone-file handling, no prompt, no write. Pinned by `switch_removes_files_absent_on_target` (Task 2) and the `GitView` refresh test (Task 6).
3. **New file inside a new folder** (`ideas/rust/a.md`, `ideas/rust/b.md`): each file listed, not `ideas/`. Pinned by `changes_lists_files_in_untracked_dirs` (Task 1).
4. **A file with only CRLF↔LF changes**: diff shows `No changes since the last commit.`-style empty diff rather than every line changed. Pinned by `diffLines ignores CR-only differences` (Task 4).
5. **Branch name that looks like an option or path trick** (`-f`, `a..b`, `main.lock`, `x y`): refused before git runs, no branch created. Pinned by `create_branch_refuses_bad_names` (Task 2) and the BranchMenu validation test (Task 7).
